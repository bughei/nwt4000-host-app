# NWT4000 上位机 (Python 版)

用于 NWT 系列扫频仪（重点适配 NWT3000/4000/6000）的桌面上位机程序，支持串口通信、实时扫频绘图、谐振点与 Q 值分析、实验分组记录，以及 CSV 导入导出。

## 主要功能

- 串口连接与自动探测（支持常见波特率探测）
- 实时扫频显示与连续扫描
- 谷点自动识别，显示谐振频率与 Q 值、1/Q
- 多曲线固定对比
- 参考底噪保存与扣底噪显示
- 曲线平滑（滑动平均）
- 普通扫频数据 CSV 导入/导出
- 实验模式分组记录与实验汇总 CSV 导出
- 扫描参数与界面状态自动缓存

## 项目结构

- `main.py`：GUI 主程序入口
- `nwt_driver.py`：串口协议与扫频线程实现
- `main.spec`：PyInstaller 打包配置
- `nwt_settings.json`：运行时自动生成的本地配置缓存
- `dist/main.exe`：已打包的 Windows 可执行文件（构建后生成）

## 运行环境

- 操作系统：Windows 10/11
- Python：3.10+（当前已在 3.14.3 下验证构建）

## 依赖安装

```powershell
python -m pip install -r requirements.txt
```

## 源码运行

```powershell
python main.py
```

## 使用说明

1. 展开“通信设置”，选择串口与设备型号。
2. 点击“打开串口”，连接成功后“开始扫描”按钮可用。
3. 在“扫描参数”中设置起始频率、终止频率和点数（频率支持 `k/m/g` 后缀）。
4. 点击“开始扫描”查看曲线与自动分析结果。
5. 需要对比时可使用“固定当前曲线”；需要去背景时先“保存当前为参考底噪”，再勾选“扣除底噪”。
6. 通过“导出CSV数据”保存当前扫频结果；实验模式下可在“实验数据记录”页导出实验汇总。

## 打包 EXE

```powershell
python -m PyInstaller --clean --noconfirm main.spec
```

构建成功后，产物位于：

- `dist/main.exe`

## 常见问题

- 打不开串口：确认端口未被其他软件占用，波特率设置正确。
- 扫频无数据：先用“一键排错探测”验证连通性，再检查设备型号倍率配置。
- EXE 被杀软拦截：将程序加入信任名单后重试。
