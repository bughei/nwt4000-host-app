## NWT4000 上位机 v1.1.0

本次发布为纯扫频版本，主要调整操作区布局和菜单入口，沿用现有扫频、绘图和分析功能，不包含促愈或电刺激演示。

### 更新内容

- 操作区改为顶部“通信 / 扫描 / 分析 / 图表”功能页。
- 增加“文件 / 设备 / 扫描 / 视图 / 工具”菜单。
- 运行日志独立成页，谐振分析和图表取点信息移至图表下方。
- 保留图表字体、轴标签字号和刻度字号设置，不包含全界面字号设置。
- 更新使用说明、更新日志和构建信息；提供 EXE、ZIP 和 SHA256 校验文件。

### 下载

- **NWT4000_monitoring.exe**：Windows 64 位单文件程序，无需 Python。
- **nwt4000-host-app-v1.1.0-win64.zip**：EXE、README、更新日志与构建信息，解压后使用。
- **SHA256SUMS.txt**：核对 EXE 和 ZIP 的 SHA256 校验值。

源码请使用下方 v1.1.0 的 Source code 附件或仓库标签。主分支已移除旧版 `dist/main.exe`，但历史标签及其 Source code 压缩包仍保留该旧文件。请勿将其或 v1.0.0 ZIP 当作最新程序；最新 EXE 以本 Release 附件为准。

### 验证与已知限制

已完成语法、GUI 初始化、频率后缀、模拟谐振谷点 Q 计算、绘图和数据处理、CSV/配置、模拟串口协议检查，并验证 EXE 在 Windows 11 64 位启动和正常退出。尚未连接实物仪器复测，尚未验证 Windows 10。

与 v1.0.0 相比，本版本扫描参数读取不再主动校验起止频率顺序及最小点数。请确保**终止频率大于起始频率、点数至少为 2**，且频率在仪器支持范围内。本次发布未修改该行为。
